# Charts Trades

Веб-приложение для просмотра истории цен и объёма торгов криптовалютами.
Использует публичный API Bitfinex без API-ключа:

- [REST API](https://api-pub.bitfinex.com/v2) — подгрузка истории свечей.
- WebSocket API: `wss://api-pub.bitfinex.com/ws/2` — обновления свечей и лента сделок в реальном времени.

## Возможности

- Пары BTC/USD, ETH/USD и SOL/USD.
- Восемь таймфреймов: от минуты до месяца.
- Свечной график и бары с ценами открытия, закрытия, максимума и минимума в легенде.
- Автоматическая подгрузка старых свечей и объёма при прокрутке влево с сохранением положения графика.
- Гистограмма объёма с переключателем и значением в базовой валюте при наведении.
- Лента 50 последних сделок выбранной пары: цена, объём, сторона и местное время; автоматическое переподключение при обрыве связи.
- Сохранение параметров графика в `sessionStorage` на время сессии вкладки.

## Стек

React, TypeScript, Vite, Lightweight Charts, SCSS Modules. Проверки: ESLint, Vitest и React Testing Library.

## Запуск

Понадобятся Node.js 20+ и npm. API-ключ не требуется.

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале.

История загружается через `/api/bitfinex/candles/` на сервере приложения: публичный REST API Bitfinex
не возвращает CORS-заголовки для прямых браузерных запросов. Прокси настроен для `npm run dev`
и `npm start` (после сборки). На хостинге настройте такой же серверный маршрут:
`/api/bitfinex/candles/*` → `https://api-pub.bitfinex.com/v2/candles/*`, сохраняя параметры запроса.
Одной раздачи файлов из `dist` для подгрузки истории недостаточно.
