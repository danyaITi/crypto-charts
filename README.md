# Charts Trades

Веб-приложение для просмотра истории цен и объёма торгов криптовалютами.
Использует публичный API Bitfinex без API-ключа:

- [REST API](https://api-pub.bitfinex.com/v2) — подгрузка истории свечей и сделок.
- WebSocket API: `wss://api-pub.bitfinex.com/ws/2` — обновления свечей и лента сделок в реальном времени.

## Возможности

- Пары BTC/USD, ETH/USD и SOL/USD.
- Таймфреймы от секунды до месяца, включая `1s`, `5s` и `10s`.
- Секундные свечи собираются из отдельных сделок с расчётом OHLC и объёма; интервалы без сделок пропускаются.
- Свечной график и бары с ценами открытия, закрытия, максимума и минимума в легенде.
- Автоматическая подгрузка старых свечей и объёма при прокрутке влево с сохранением положения графика.
- Гистограмма объёма с переключателем и значением в базовой валюте при наведении.
- Лента 50 последних сделок выбранной пары: цена, объём, сторона и местное время; автоматическое переподключение при обрыве связи.
- Сохранение параметров графика в `sessionStorage` на время сессии вкладки.

## Стек

React, TypeScript, Vite, Lightweight Charts, SCSS Modules. Проверки: ESLint, Vitest и React Testing Library.

## Запуск

Понадобятся Node.js 20+ и npm. API-ключ не требуется.

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале.

История загружается через `/api/bitfinex/candles/` и `/api/bitfinex/trades/` на сервере приложения: публичный REST API Bitfinex
не возвращает CORS-заголовки для прямых браузерных запросов. Прокси настроен для `npm run dev`
и `npm start` (после сборки). На хостинге настройте такой же серверный маршрут:
`/api/bitfinex/candles/*` → `https://api-pub.bitfinex.com/v2/candles/*`, сохраняя параметры запроса.
Для секундных интервалов также нужен маршрут `/api/bitfinex/trades/*` → `https://api-pub.bitfinex.com/v2/trades/*`.
Их история строится из сделок порциями до 5000 записей (до 10000 на плотной границе), с интервалом между запросами не менее 4,1 секунды.
Крайняя старая свеча отображается после догрузки её сделок, чтобы не показывать неполный объём.
Одной раздачи файлов из `dist` для подгрузки истории недостаточно.

## Развёртывание на Vercel

В корне проекта есть `vercel.json`: правила `rewrites` пересылают запросы истории свечей и сделок в публичный API Bitfinex.
Параметры `limit`, `sort` и `end` сохраняются. Прокси из `vite.config.ts` используется только локально, а на Vercel работают эти правила.
После изменения `vercel.json` нужен новый деплой из коммита с этим файлом; переменные окружения и API-ключ не требуются.

Для проверки откройте `/api/bitfinex/candles/trade:1m:tBTCUSD/hist?limit=2&sort=-1` на домене сайта:
должен вернуться JSON-массив свечей с кодом `200`. Маршрут `/api/bitfinex/trades/tBTCUSD/hist?limit=2&sort=-1`
должен вернуть JSON-массив сделок. Пустой массив `[]` на запрос старых данных означает конец доступной истории.
