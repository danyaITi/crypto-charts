# Charts Trades

Веб-приложение для просмотра истории цен и объёма торгов криптовалютами.
Данные поступают в реальном времени через публичный WebSocket API Bitfinex.

## Возможности

- Пары BTC/USD, ETH/USD и SOL/USD.
- Восемь таймфреймов: от минуты до месяца.
- Свечной график и бары с ценами открытия, закрытия, максимума и минимума в легенде.
- Гистограмма объёма с переключателем и значением в базовой валюте при наведении.
- Лента 50 последних сделок выбранной пары: цена, объём, сторона и местное время; автоматическое переподключение при обрыве связи.
- Сохранение параметров графика в `sessionStorage` на время сессии вкладки.

## Стек

React, TypeScript, Vite, Lightweight Charts, SCSS Modules. Проверки: ESLint, Vitest и React Testing Library.

## Запуск

Понадобятся Node.js 20+ и npm. API-ключ не требуется.

```bash
npm ci
npm run dev
```

Откройте адрес, который Vite выведет в терминале.

| Команда                | Назначение                            |

| `npm test`             | Запуск тестов                         |
